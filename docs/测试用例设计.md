# 每日记事本 · 测试用例设计

> 版本基线：v1.9.9 ｜ 用例编号规则：`模块缩写-序号`（`PR`=解析、`TK`=勾选撤销、`HS`=历史、`LG`=中英、`TH`=换肤、`RM`=提醒、`OB`=引导、`XD`=跨天）
> 「对应文档条目」指向 `使用说明.md` 的小节号与原文关键词，便于逐条回溯。
> 标注 **P1** 的用例是用户重点关注的五件事（解析准确率、跨天正确性、不串语言、提醒不重复、时钟不停），回归必跑。

## 一、任务解析（PR）

解析器是整个软件的入口，一次误判用户就得多改三遍。用例按「输入 → 期望结构」写，全部可自动化。

| 编号 | 前置条件 | 操作步骤 | 预期结果 | 对应文档条目 |
|---|---|---|---|---|
| PR-01 **P1** | 今日为空；语言=中文 | 输入 `买牛奶` | 新增 1 条任务，标题=`买牛奶`，`hhmm` 为空，`score`=30（一般） | 九、「直接用大白话」；缺少时间即无截止 |
| PR-02 **P1** | 同上 | 输入 `9点开会，下午3点前交周报，顺便买瓶酱油` | 拆成 **3 条**；标题分别为 `开会`/`交周报`/`买瓶酱油`；前两条有 `hhmm`，第三条无 | 九、示例 1「一句话塞多件事」 |
| PR-03 **P1** | 同上 | 输入 `明天上午10点体检，非常重要` | 1 条任务；`hhmm`=`10:00`；`due_date`=明日；`score` ≥ 75（重要） | 九、示例 2；「非常重要」判重要性 |
| PR-04 | 同上 | 输入 `整理时间表` | 标题必须完整为 `整理时间表` | 九、任务标题保留原文 |
| PR-05 | 同上 | 输入 `时间管理课` | 标题为 `时间管理课`，不得被啃成 `间管理课` | 同 PR-04（v1.9.9 修复点） |
